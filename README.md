**תנ"ך כמסע: הכתובת החיה תיכתב אחרי הפריסה ב-Vercel.**

סיפורים בארבע קומות פרשנות (פשט, רמז, דרש, סוד), מפות מסע, ציר זמן ויחסי דמויות, כל טענה עם מקור.

## הרצה
```bash
npm install
npm run dev
```

## בדיקה
```bash
npm run build
npm run preview &
npm run test:e2e
```

## מבנה
- `src/content/`: הסיפורים, המסעות, ציר הזמן והדמויות. התוכן נכתב כאן, לא בקומפוננטות.
- `src/components/`: הקומפוננטות המשותפות: סרגל, טקסט עשיר, ערימת הקומות, מפת המסע.
- `src/pages/`: דפי האפליקציה.
- `scripts/`: בדיקת קצה לקצה ויצירת אייקון.

## החלטות
- ניתוב לפי hash, כדי שכל תצוגה תישמר בקישור.
- יומן ב-localStorage בלבד, בלי שרת.
- מפה סכמטית ולא גיאוגרפית מדויקת. הדבר מצוין בדף.
